# Google Icons for PowerPoint 導入手順（Mac）

PowerPoint の右側にパネルを出し、Google の Material Symbols（約3,900種）を日本語・英語で検索して、クリックでスライドに挿入するアドインです。挿入されるのは SVG なので、拡大しても粗くならず、色も後から変えられます。

- 対象: Mac の PowerPoint（Microsoft 365）。Windows では使えません
- インターネット接続が必要です（パネル本体とアイコンをネットから読み込むため）

## 同梱物

| ファイル | 役割 |
|---|---|
| `install.sh` | 下の3つを所定の場所に置くスクリプト |
| `google-icons-manifest.xml` | アドインの定義 |
| `GoogleIconsLauncher.pptx` | 開くとアドインが読み込まれる起動用ファイル |
| `GoogleIconsLoader.txt` | 起動時の読み込みの設定 |
| `GoogleIcons.ppam` | PowerPoint の起動時に、起動用ファイルを数秒開いて閉じるマクロ |

社内の PowerPoint では、自分で追加したアドインが終了時に外れてしまうため、`GoogleIcons.ppam` が起動のたびに読み込み直します。

## 導入（5分）

1. zip を展開します。
2. ターミナルで、展開したフォルダに移動して次を実行します。
   ```
   bash install.sh
   ```
3. PowerPoint で **ツール → PowerPoint アドイン → ＋** を押し、**書類 → GoogleIcons → GoogleIcons.ppam** を選んで開きます。
4. 「マクロを有効にしますか」と聞かれたら **有効にする** を選び、一覧にチェックが入っていることを確かめて **OK** を押します。
5. PowerPoint を **⌘Q** で終了して起動し、プレゼンテーションを開きます。起動用ファイルが数秒開いて閉じたあと、**挿入タブに「Google Icons」** が出れば完了です。

## 使い方

- 挿入タブの「Google Icons」でパネルを開きます
- 検索は日本語・英語どちらでも（矢印、家、グラフ、chart など）。「上矢印」のような続け書きも分けて探します
- Outlined / Rounded / Sharp、塗り、太さ、サイズ（cm）を選んでからアイコンをクリック
- 色は色見本から。「＋登録」で案件の色を保存、右クリックで削除
- 「選択中と差し替え」にチェックを入れ、スライド上のアイコンを1つ選んでから別のアイコンをクリックすると、同じ位置・大きさで入れ替わります（1回ごとにチェックは外れます）

## うまくいかないとき

- **起動しても挿入タブにボタンが出ない**: 次の記録ファイルを確認します。
  `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/GoogleIconsLoader.log`
  - 起動直後に `error ... 'Open'` が1行出るのは正常です（スタート画面ではファイルを開けないため。プレゼンテーションを開いたときの2回目で読み込まれます）
  - `opened` → `closed` まで進んでいるのにボタンが出ない場合は、同じフォルダの `GoogleIconsLoader.txt` を調整します
    - `wait=8` を `wait=15` に延ばす（PC 再起動直後は読み込みが遅いため）
    - それでも外れる場合は `close=0`（起動用ファイルを閉じずに最小化して残す）
- **今すぐ使いたい**: `GoogleIconsLauncher.pptx` を Finder で開くと、そのセッションではボタンが出ます
- **アドインの一覧に何も出ない／ツールメニューが違う**: PowerPoint を最新版に更新してください

## 削除

1. ツール → PowerPoint アドイン で GoogleIcons を選び **−**
2. 次のファイルを削除
   - `~/Documents/GoogleIcons/`
   - `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/google-icons-manifest.xml`
   - 同じフォルダの `GoogleIconsLauncher.pptx`、`GoogleIconsLoader.txt`、`GoogleIconsLoader.log`

## Claude に頼む場合

この手順書と zip を渡して「この手順で Google Icons を導入して」と頼めば、手順2（スクリプト実行）までは Claude が進められます。手順3〜5は PowerPoint の画面操作なので、本人が行います。導入後にボタンが出ないときは、上の記録ファイルを Claude に読ませると原因を絞れます。
